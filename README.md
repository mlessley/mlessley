### Mark Lessley — Platform & Network Automation Engineer

Automating and optimizing network operations through workflow orchestration and AI-driven engineering.

**Projects**

* 🌐 [`network-ztp`](https://github.com/mlessley/network-ztp) — Zero-touch provisioning proof-of-concept for network devices. Uses Temporal, Nautobot, and Ansible to orchestrate bootstrap, provisioning, and compliance, with human-in-the-loop escalation on drift.
* 🔍 [`pipeline-lens`](https://github.com/mlessley/pipeline-lens) — Links events across the delivery lifecycle (GitHub → build/scan → deployment) into a single queryable record, with a Neo4j lineage layer in progress.
* 🛡️ [`dast-bench`](https://github.com/mlessley/dast-bench) — Evaluation framework for DAST tools. Includes a versioned criteria taxonomy, CI benchmark runs against known-vulnerable targets, and YAML-generated scorecards.
* 🧰 [`devx`](https://github.com/mlessley/devx) — Cross-platform containerized dev environment (Windows/WSL2, macOS, Linux) with Claude Code preinstalled, optional toolchain and service overlays, and multi-instance support.
* 🤖 [`hybrid-rag-watsonx`](https://github.com/mlessley/hybrid-rag-watsonx) — Document Q&A system that routes RAG queries between local M4 inference and IBM watsonx.ai.
* 🔎 [`codebase-rag`](https://github.com/mlessley/codebase-rag) — Natural-language Q&A over Python codebases, using ChromaDB indexing and a LangGraph agent for file- and line-level retrieval.
